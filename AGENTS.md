If the primary mechanism isn't available, fail loudly (raise / log / return empty) — do NOT silently substitute a weaker path. If you believe a fallback is genuinely needed, STOP and ask the user before writing it; describe the primary, the proposed fallback, and why. Default is always: one correct path, no duplication, no second-guessing.

The rule means: wherever you would normally stop, instead call `vscode_askQuestions` / `askUser` to prompt the user to continue the thread/topic/task. You can't forget about this. - **`main` is expected to be one commit behind right after you push — that is CI, not a mistake.** `.github/workflows/release.yml` runs on every push to `main`: it computes the next version from the conventional commits since the last tag (`scripts/bump_version.py`, range `vX.Y.Z..HEAD`), writes it into `custom_components/powerpilot/manifest.json`, and pushes that `chore(release): vX.Y.Z [skip ci]` commit straight to `main`, then tags and publishes a GitHub Release. The bump has to land in the tree because `hacs.json` declares no `zip_release`, so HACS installs the repo content at the tag and reads the version from the committed manifest. Consequences when working here:
  - Before every push, expect a non-fast-forward if a release was cut since your last pull. `git pull --rebase origin main` first; the release commit only touches `manifest.json`, so it never conflicts with feature work.
  - **Always verify a push actually landed** — `git ls-remote origin refs/heads/main` or `git status -sb`. The rtk proxy has reported a rejected push as "ok", and stale code then gets tested as if it shipped.
  - Never hand-edit the version in `manifest.json` to "fix" the drift; `bump_version.py` derives it from the tag and the commit range.
  - Do not move the bump into a git hook. It is computed over a commit *range*, so a per-commit hook would inflate the version on any multi-commit push; hooks are also machine-local (`core.hooksPath` here already points outside the repo), bypassable with `--no-verify`, and absent for commits made off this machine.
